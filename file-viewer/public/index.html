📂 Local File Viewer
Chưa chọn file

Nhập một đường dẫn thư mục ở trên rồi bấm Mở.

Hỗ trợ xem: .txt .csv .log .md .xml .yml .ini .js .ts .sql … dạng text có số dòng; .json tự động format đẹp; ảnh xem trực tiếp; file nhị phân xem dạng hex.

⇄ So sánh file / thư mục

Nhập hai đường dẫn cùng loại (hai file hoặc hai thư mục).

File tiếng Nhật do WinForm xuất thường là Shift_JIS. Để Tự động là đọc đúng; kết quả tách riêng “giống từng byte” và “giống nội dung sau khi decode”, nên khác bảng mã sẽ không bị báo nhầm thành sai dữ liệu.
